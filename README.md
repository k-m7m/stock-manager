# 株式ポートフォリオ管理アプリ

シンプルで使いやすい株式ポートフォリオ管理Webアプリケーションです。

## デモ

GitHub Pagesで公開中: https://k-m7m.github.io/stock-manager/

> **Note**: 初回デプロイ後、GitHub Pagesの設定を有効化する必要があります。下記の「GitHub Pagesでの公開」セクションをご覧ください。

## 機能

### データ管理
- 購入した株の銘柄名と株数を登録・保存
- データはブラウザのローカルストレージに自動保存
- 銘柄の追加、編集、削除

### 表示項目
以下の情報を一覧表示します：
1. **銘柄名** - 株式の名称
2. **購入株数** - 保有している株数
3. **現在株価** - 1株あたりの現在価格（円）
4. **評価額** - 現在株価 × 購入株数（円）
5. **配当利回り** - 年間配当利回り（%）
6. **年間配当金額** - 1株あたりの年間配当金額（円）
7. **年間配当総額** - 年間配当金額 × 購入株数（円）
8. **全銘柄の配当総計** - すべての銘柄の年間配当総額の合計

### 自動計算機能
- 評価額を自動計算（株価 × 株数）
- 年間配当金額を自動計算（株価 × 配当利回り ÷ 100）
- 年間配当総額を自動計算（年間配当金額 × 株数）
- 全銘柄の評価額合計と配当総計を自動集計

## GitHub Pagesでの公開

このアプリはGitHub Pagesで公開できるように設定されています。

### 初回設定手順

1. GitHubリポジトリページを開く
2. **Settings** タブをクリック
3. 左サイドバーから **Pages** をクリック
4. **Source** セクションで以下を選択：
   - Source: `GitHub Actions`
5. 保存後、自動的にデプロイが開始されます

### デプロイの確認

- **Actions** タブでワークフローの実行状況を確認できます
- デプロイ完了後、`https://<ユーザー名>.github.io/stock-manager/` でアクセス可能

### 自動デプロイ

- `claude/stock-portfolio-app-XcVHM` ブランチへのプッシュ時に自動的にデプロイされます
- **Actions** タブから手動でもデプロイ可能です

## 使い方

### 起動方法（ローカル）
1. `index.html` をブラウザで開く
2. ファイルをダブルクリック、またはブラウザにドラッグ&ドロップ

### 起動方法（オンライン）
- GitHub Pagesの公開URLにアクセス

### 銘柄の追加
1. 上部のフォームに以下を入力：
   - 銘柄名（例: トヨタ自動車）
   - 購入株数（例: 100）
   - 現在株価（例: 2000）
   - 配当利回り（例: 3.5）
2. 「追加」ボタンをクリック
3. 一覧表に自動的に追加され、計算結果が表示されます

### 銘柄の編集
1. 一覧表の「編集」ボタンをクリック
2. フォームに現在のデータが自動入力されます
3. 必要な項目を修正
4. 「更新」ボタンをクリック

### 銘柄の削除
1. 一覧表の「削除」ボタンをクリック
2. 確認ダイアログで「OK」を選択

## 技術仕様

- **フロントエンド**: HTML5, CSS3, JavaScript (ES6+)
- **データ保存**: localStorage API
- **レスポンシブ対応**: スマートフォン、タブレット、デスクトップ
- **ブラウザ要件**: モダンブラウザ（Chrome, Firefox, Safari, Edge）

## ファイル構成

```
stock-manager/
├── index.html    # メインHTMLファイル
├── style.css     # スタイルシート
├── app.js        # アプリケーションロジック
└── README.md     # このファイル
```

## 注意事項

- データはブラウザのlocalStorageに保存されるため、ブラウザのキャッシュをクリアするとデータが失われます
- 株価と配当情報は手動で入力・更新する必要があります（自動取得機能はありません）
- インターネット接続は不要で、完全にオフラインで動作します
