# 株式ポートフォリオ管理アプリ

シンプルで使いやすい株式ポートフォリオ管理Webアプリケーションです。

## デモ

GitHub Pagesで公開中: https://k-m7m.github.io/stock-manager/

> **Note**: 初回デプロイ後、GitHub Pagesの設定を有効化する必要があります。下記の「GitHub Pagesでの公開」セクションをご覧ください。

## 機能

### データ管理
- **証券コードと株数のみで簡単登録**
- Yahoo Finance APIから自動的に最新情報を取得：
  - 銘柄名
  - 現在株価
  - 配当利回り
- データはブラウザのローカルストレージに自動保存
- 銘柄の追加、編集、削除
- ワンクリックで全銘柄の株価を一括更新

### 表示項目
以下の情報を一覧表示します：
1. **証券コード** - 4桁の証券コード（例: 7203）
2. **銘柄名** - 株式の名称（APIから自動取得）
3. **購入株数** - 保有している株数
4. **現在株価** - 1株あたりの現在価格（円、APIから自動取得）
5. **評価額** - 現在株価 × 購入株数（円、自動計算）
6. **配当利回り** - 年間配当利回り（%、APIから自動取得）
7. **年間配当金額** - 1株あたりの年間配当金額（円、自動計算）
8. **年間配当総額** - 年間配当金額 × 購入株数（円、自動計算）
9. **全銘柄の配当総計** - すべての銘柄の年間配当総額の合計（自動計算）

### 自動計算機能
- 評価額を自動計算（株価 × 株数）
- 年間配当金額を自動計算（株価 × 配当利回り ÷ 100）
- 年間配当総額を自動計算（年間配当金額 × 株数）
- 全銘柄の評価額合計と配当総計を自動集計

## GitHub Pagesでの公開

このアプリはGitHub Pagesで公開できるように設定されています。

### 初回設定手順

1. GitHubリポジトリページを開く
2. **Settings** タブをクリック
3. 左サイドバーから **Pages** をクリック
4. **Source** セクションで以下を選択：
   - Source: `GitHub Actions`
5. 保存後、自動的にデプロイが開始されます

### デプロイの確認

- **Actions** タブでワークフローの実行状況を確認できます
- デプロイ完了後、`https://<ユーザー名>.github.io/stock-manager/` でアクセス可能

### 自動デプロイ

- `claude/stock-portfolio-app-XcVHM` ブランチへのプッシュ時に自動的にデプロイされます
- **Actions** タブから手動でもデプロイ可能です

## 使い方

### 起動方法（ローカル）
1. `index.html` をブラウザで開く
2. ファイルをダブルクリック、またはブラウザにドラッグ&ドロップ

### 起動方法（オンライン）
- GitHub Pagesの公開URLにアクセス

### 銘柄の追加
1. 上部のフォームに以下を入力：
   - **証券コード**（例: 7203 = トヨタ自動車）
   - **購入株数**（例: 100）
2. 「追加」ボタンをクリック
3. 自動的にYahoo Finance APIから最新の株価・銘柄名・配当利回りを取得
4. 一覧表に追加され、評価額や配当金額が自動計算されます

### 株価の更新
- 「全銘柄を更新」ボタンをクリックすると、すべての銘柄の最新株価・配当情報を取得します
- 市場の取引時間外は前日終値が表示されます

### 銘柄の編集
1. 一覧表の「編集」ボタンをクリック
2. 株数を修正して「更新」ボタンをクリック
3. 証券コードは変更できません（別の銘柄として追加してください）

### 銘柄の削除
1. 一覧表の「削除」ボタンをクリック
2. 確認ダイアログで「OK」を選択

### 証券コード例

主要な日本株の証券コード：
- **7203** - トヨタ自動車
- **6758** - ソニーグループ
- **9984** - ソフトバンクグループ
- **9983** - ファーストリテイリング（ユニクロ）
- **8306** - 三菱UFJフィナンシャル・グループ
- **6501** - 日立製作所
- **7974** - 任天堂
- **4063** - 信越化学工業

証券コードは各企業の公式サイトや証券会社のサイトで確認できます。

## 技術仕様

- **フロントエンド**: HTML5, CSS3, JavaScript (ES6+)
- **データ取得**: Yahoo Finance API（非公式、無料）
- **データ保存**: localStorage API
- **API通信**: Fetch API（非同期処理）
- **レスポンシブ対応**: スマートフォン、タブレット、デスクトップ
- **ブラウザ要件**: モダンブラウザ（Chrome, Firefox, Safari, Edge）
- **インターネット**: 株価取得時のみ必要

## 注意事項

- データはブラウザのlocalStorageに保存されるため、ブラウザのキャッシュをクリアするとデータが失われます
- **株価・配当情報の取得にはインターネット接続が必要です**
- 株価データはYahoo Finance APIから取得しています（無料・認証不要）
- 市場の取引時間外は前日終値が表示されます
- 配当利回りが0と表示される場合は、その銘柄の配当情報が取得できていません
- API利用の制限により、大量のリクエストを短時間に行うと一時的にアクセスできなくなる場合があります
